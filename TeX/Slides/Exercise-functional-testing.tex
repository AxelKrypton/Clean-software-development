\begin{frame}[t]{A new begin}
    \vspace{-2mm}
    \begin{enumerate}
        \item Choose a test framework for the language of your snippet
        \item Reflect on the the difference between unit and functional tests
        \item Set up the test framework and write \PP{a dummy unit test}
        \item Is the framework suitable for functional tests?
        \item Add at least \PP{one meaningful functional test} to your project
        \item \alert{Commit and push your code in a dedicated folder under \:\Emoji{file-folder}\,\texttt{src}}\\
              \then {\small Add a suitable \texttt{.gitignore} file $\;\to\;$Check out \URL[PS]{https://github.com/github/gitignore}{this project}}
    \end{enumerate}
