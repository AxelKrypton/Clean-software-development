To install all required dependencies run:
```bash
$ julia --project -e "using Pkg; Pkg.instantiate()"
```
Run the code using:
```bash
$ julia --project src/Powerweek.jl 
```
Run the tests ("Magic Button"):
```bash
$ julia --project -e "using Pkg; Pkg.test()"
```

## Setup
1. To quickly get starated with julia, install it from [here](https://julialang.org/install/)
2. Go to you favorite terminal and navigate into the `Leon_Code_Snippet` folder and run `$ julia --project`
3. After that, hit `]`. It should display you `(Powerweek) pkg> `.
4. If you type `test` and hit `enter` it should run all tests. 

_Note: It might does some installation and precompilation during the previous steps._
